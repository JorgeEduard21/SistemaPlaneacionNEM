¿Cómo saber que esta es la versión oficial y segura?

Para evitar que personas malintencionadas compartan versiones alteradas, este proyecto es 100% transparente y de código abierto:

1. Código Fuente Abierto

Cualquier maestro, especialista en tecnologías o directivo puede auditar cada línea de código en nuestro repositorio oficial de GitHub.

Ver repositorio oficial →

2. Motor Oficial Firmado Digitalmente

El motor interno de ejecución está firmado por la Python Software Foundation (DigiCert), asegurando que Windows no lo detecte como archivo sospechoso.

3. Verificación de Huella Digital (SHA-256)

Comprueba que tu archivo descargado coincide exactamente con el original ejecutando en PowerShell:

Get-FileHash Instalador_Planeacion_NEM_v1.0.0.exe

Preguntas Frecuentes

¿El programa tiene algún costo o cobro mensual?

No. El programa es 100% gratuito y de código libre. No requiere pagos, suscripciones ni donaciones obligatorias.

¿Qué es la API Key de Gemini y cuesta dinero?

La API Key es un permiso gratuito que te da Google para comunicarte con su modelo de inteligencia artificial. No pide tarjetas de crédito ni datos de pago, y su cuota gratuita es más que suficiente para crear tus planeaciones del ciclo escolar.

¿Necesito tener Microsoft Word instalado?

No necesariamente. La aplicación cuenta con un botón directo para Abrir e Insertar en Google Docs en la nube completamente gratis, o bien puedes descargar el archivo .docx y abrirlo con LibreOffice o Word si lo tienes.

¿Se envían los datos de mis alumnos a algún servidor privado?

No. El programa guarda toda la información únicamente en el disco duro de tu computadora (en la carpeta segura de tu usuario de Windows). Solo se envían a Google los criterios pedagógicos que seleccionas para que el modelo redacte tu secuencia didáctica.

¿Qué versiones de Windows son compatibles?

Es compatible con Windows 10 y Windows 11 de 64 bits. Viene con todos los complementos incluidos en el instalador.
